# Studio Booking — Web

Frontend (Next.js + Tailwind) de la plataforma de reservas para barberías, salones, spa y estudios de uñas: landing pública, flujo de reserva y panel administrativo.

La API vive en [barber-shop-back](https://github.com/sebastian-barrera-herrera/barber-shop-back).
